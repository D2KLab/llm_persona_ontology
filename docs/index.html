LLM Persona Ontology

The LLM Persona Ontology provides a structured model for representing personas used to guide, configure, describe, or evaluate LLM-based agents and roles. It organises persona information around the identity and behaviour pillars.

This ontology defines 7 classes and 91 properties.

See it on GitHub
The LLM Persona Ontology provides a structured model for representing personas used to guide, configure, describe, or evaluate LLM-based agents and roles. It models both Identity (demographic, biographical, and social characteristics) and Behaviour (personality, goals, preferences, reasoning styles, and behavioural constraints), enabling personas to be represented, queried, compared, and edited independently of natural-language prompts. Rather than describing personas as free-text prompts, it encodes identity, behavioural characteristics, preferences, goals, and constraints as structured RDF knowledge. This enables semantic querying, validation, comparison, reuse, and automatic generation of persona prompts while remaining interoperable with existing Semantic Web vocabularies.
An example of a persona represented in the ontology is shown below: 
 ex:persona a llmp:LLMPersona ;
  llmp:hasAgentType llmpv:NaturalPerson ;
  llmp:hasApparentAge "58"^^xsd:integer ;
  llmp:hasOccupation ex:Artist ;
  llmp:hasHomeLocation ex:NewYork ;
  llmp:hasInterest ex:Volunteering ;
  llmp:hasSpecies ex:Human .
